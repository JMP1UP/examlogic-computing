# AI use review

## Current use

StudySpice uses optional model assistance in two bounded formative workflows:

- the programming tutor uses the current challenge, learner code and objective
  test evidence to return one diagnosis, one hint and one check question;
- written-answer coaching uses an original question, command word, rubric and
  learner response to return a cautious estimate and improvement prompt.

Both routes treat learner input as untrusted content, use structured outputs,
have deterministic fallbacks and avoid target-grade claims, complete solutions
and automatic mastery. Checked evidence remains the source for attainment.
Requests are pupil initiated, rate limited and capped to short structured
responses. The reviewed question bank remains the source for custom papers;
models do not generate live pupil assessment items.

## Effective boundaries

- Deterministic tests remain authoritative for executable behaviour.
- AI feedback does not create badges, completion, checkpoints or class marks.
- Teacher assessment reports and topic judgements remain a separate source.
- The markbook does not ask a model to infer risk, confidence or intervention.

## Gaps and next controls

1. Show the feedback source consistently wherever AI or fallback feedback appears.
2. Make the school-level control describe both writing and programming assistance.
3. Define retention, deletion and provider-processing guidance for live pupil data.
4. Monitor availability, fallback and unsafe-output rejection without logging
   unnecessary pupil text.
5. Require teacher moderation before an AI estimate can become a summative mark.
6. Do not generate class summaries until every claim cites correctable evidence.
7. Add a durable school-level spend ceiling before increasing request volume.
8. Any teacher-facing question draft must remain unpublished until a subject
   specialist has checked its originality, mapping, answer and mark scheme.

## Decision

AI is effective for the current narrow formative purposes. It should not be
expanded into automated markbook judgements or summative marking during this
phase. Assessment reporting remains teacher-authored and specification-linked.
