# Documentation guide

## Current source of truth

Read `design.md`, `architecture.md`, `data-model.md`, `user-flows.md`, `decisions.md`, `roadmap.md`, and `release-checklist.md` first. `curriculum-map.md`, `assessment-reference-index.md`, `theory-coverage-audit.md`, and `question-bank-strategy.md` govern curriculum and assessment integrity. `ai-use-review.md` governs current AI boundaries.

## Specialist specifications

`student-navigation-spec.md` defines the intended student information architecture. `MULTI_SCHOOL_ARCHITECTURE.md` defines the multi-school target and must not be used to claim that every production control is already deployed.

## Evidence rule

Implementation and automated tests establish current behaviour. Curriculum claims require traceable assessed evidence; plans, coverage targets, and design aspirations do not by themselves prove delivered coverage or safe marking.
